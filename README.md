# Avalonia Application Boilerplate

## Requirements

### Common

For building:

- __.NET SDK 8__.

For development:

- __Git__;
- __Visual Studio 2022__, __Visual Studio Code__ or __Rider__.

### Android

For building and development:

- __JDK 11__;
- __Android SDK Build-Tools 34__;
- __Android SDK Command-line Tools 11__.

### iOS

For building and development:

- __macOS__;
- __Xcode Command-line Tools__;
- __Xcode 26.0__:
  - __iOS 26.0 + iOS 26.0.1 Simulator__.

## Building

Building for Windows, Linux, macOS, WebAssembly, Android and iOS targets supported.
See [build instructions](./doc/build-instructions.md) for details.
